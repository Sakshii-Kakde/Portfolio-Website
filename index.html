The Simon Say Game is a web-based memory game designed to test and improve the player's concentration and memory skills. The game generates a sequence of colored buttons that the player must observe and repeat in the correct order. The application provides an interactive interface with visual effects and user input validation to create an engaging gaming experience. Tic-Tac-Toe Game

The Tic-Tac-Toe Game is a web-based interactive game developed to provide an engaging two-player gaming experience. The application allows two players to take turns marking X and O on a 3×3 game board while automatically checking for winning combinations after each move. Once a player achieves a winning pattern, the game displays the winner and prevents further moves until a new game is started or the board is reset. The project features an intuitive user interface, real-time winner detection, and game reset functionality for continuous gameplay. Built using HTML, CSS, and JavaScript, the project demonstrates core front-end development concepts such as DOM manipulation, event handling, conditional logic, game state management, and dynamic user interaction.
